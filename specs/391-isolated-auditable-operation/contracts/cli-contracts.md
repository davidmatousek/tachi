# CLI Contracts (Feature 391)

House conventions for all three: `#!/usr/bin/env python3`, module docstring with feature id, purpose, constraints (stdlib-only) and exit codes; `from __future__ import annotations`; `_build_arg_parser()` with `prog=`; `main(argv=None) -> int`; `raise SystemExit(main())`; errors to stderr with a `[391]` prefix; `--json` prints `json.dumps(summary, sort_keys=True, indent=2)`.

## `scripts/check-agent-privileges.py` (Part A3)
```
python3 scripts/check-agent-privileges.py [--repo-root PATH]
    [--matrix docs/standards/CLAUDE_PERMISSIONS.md]
    [--agents-dir .claude/agents/tachi] [--commands-glob ".claude/commands/tachi.*.md"]
    [--runbook docs/guides/ISOLATED_OPERATION_TACHI.md] [--self-test] [--json]
```
Checks, all run, all reported: **C1 roster**, bidirectional (walk the agents dir recursively; a symlink anywhere is red; a file with leading YAML frontmatter — detected leniently: BOM, blank lines, CRLF tolerated — is an agent candidate and must carry `name: tachi-*`, unique, with a §8 row; the allow-list (`_TACHI_AGENT_BEST_PRACTICES.md`) applies only to files with **no** leading frontmatter, so an allow-listed name that gains frontmatter is classified as an agent candidate; anything else is red; and every §8 row must have a file); **C2 tools** set equality per agent (block list, flow list and comma string all parsed; any other shape → exit 2); **C3 model** equality; **C4 key set** == `{name, description, tools, model}`; **C5 command frontmatter** equals the §8 commands table's recorded keys; **C6 Bash families**: in fenced blocks labelled `bash`, `sh`, `shell` or `zsh` (indented fences included; unlabelled fences out of scope, and agent commands must use labelled fences) of the three Bash-capable agents: join `\` continuations, split on `&&`, `||`, `;` and `|`, strip leading `VAR=value` assignments, take each segment's first token, require it ∈ the per-agent allow-list; `$(…)`, backticks, `eval`, `bash -c`/`sh -c` and `xargs <cmd>` are red unless allow-listed; prose is never scanned; **C7 writes cross-check**: the runbook's write-locations table equals the §8 writes column; **C8 self-test** (`--self-test`): copy the tree to a temp dir and assert a failure for each mutation: a tool added to one agent; a planted `name: helper` agent; an unlisted file without frontmatter; a duplicate name; `_TACHI_AGENT_BEST_PRACTICES.md` with planted frontmatter. Exit **0** pass, **1** drift (every finding listed), **2** infra (matrix/section missing, unparsable frontmatter, self-test did not fail). The §8 table is parsed between `## 8.` and `## Cross-references`. CI: a `python3` presence step precedes it in `tachi-permissions-verify.yml`.

## `scripts/archive-run-transcripts.py` (Part B1)
```
python3 scripts/archive-run-transcripts.py (--session SESSION_ID | --latest)
    [--project-dir PATH=cwd] [--dest PATH] [--output-dir PATH]
    [--allow-live] [--live-window-seconds 120] [--json]
```
Discovery: `~/.claude/projects/` (or `$CLAUDE_CONFIG_DIR/projects/`), the project found by matching transcripts' `cwd` to `realpath(--project-dir)`; `--latest` = newest main transcript for that project. Destination default `~/.tachi/runs/<project-dir-name>/<YYYY-MM-DD>-<session>/` (date = first timestamp, UTC). Refusals (exit 1, reason on stderr): destination's nearest existing ancestor inside a git work tree unless `git check-ignore -q <dest>/.probe` passes; non-empty destination (unless the existing archive's transcript hashes match → exit 0 no-op); live session (any transcript mtime within the window) without `--allow-live`; symlink in the destination path resolving into a work tree. Writes: dirs 0700, files 0600, `O_EXCL`; copies `<session>.jsonl` and the whole `<session>/` directory verbatim. Manifest per `run-manifest.md`; parse failures and the final secret scan exit 1 with no manifest written. Exit 2: missing projects dir, unreadable transcript, `git` absent when a work-tree check is needed. Runs from a plain shell after the session (under the profile's sandbox the default destination is unwritable by design), under the same secret-injection wrapper as the session so the final scan sees the same values. Copies without following symlinks. Archives are never swept. Attribution follows dispatches at any depth (see `run-manifest.md`). Python ≥ 3.9 (chunked `hashlib.sha256().update`, `timezone.utc`). Joins `INSTALL_MANIFEST.md`'s script whitelist.

## `scripts/stamp-tachi-version.py` (Part B2)
```
python3 scripts/stamp-tachi-version.py --threats PATH [--marker templates/tachi/VERSION]
    [--schema-version-from-template] [--check] [--json]
```
Idempotent: inserts `tachi_version: "<value>"` immediately after `schema_version:` in the YAML frontmatter, or updates it; `<value>` from the marker line or `unknown` when the marker is absent or malformed (reason to stderr). With `--schema-version-from-template` (CF-21, enabled only if the scratch-clone measurement shows zero baseline churn) it also writes `schema_version` from the template constant. `--check` exits 2 if the file would change. Exit 0 stamped or unchanged, 1 I/O or no frontmatter. Invoked at the command layer as **Step 2.6 of `.claude/commands/tachi.threat-model.md`**, between the Step 2.5 populator re-assert and Step 3; `orchestrator.md` is untouched; the model never writes the field. When `schema_version:` is absent the field is appended at the end of the frontmatter. `--schema-version-from-template` reads the single source `schemas/output.yaml`. Python ≥ 3.9 (no `hashlib.file_digest`, no `datetime.UTC`).
