## Knowledge Base Findings
- **Entry 3 (F-256)** — path filter and pytest invocation must change lock-step when a new test file joins a tracked workflow. Applies to the guard test (FR-012) and any new `tests/scripts` module.
- **Entry 5 (F-4)** — permissions baseline: cross-list precedence and transitive subdomain collapse; built-in read-only auto-approve survives without explicit allow. Background for FR-003's coverage-gap statements and the §8 matrix in `CLAUDE_PERMISSIONS.md`.
- **Entry 19 (F-329)** — guard an invariant at logic level with the renderer's own loader; emit expected values as the final step of regeneration. Pattern for the guard: derive the expected roster from the frontmatter the runtime reads, not from a hand-typed copy.
- **Entry 20 (F-281)** — porting a local check into CI is a near-1:1 clone of a sibling workflow plus the delivered script; the only net-new line is a tool presence guard. Supports D-4: extend `tachi-permissions-verify.yml` rather than build a new workflow.
- **Entry 22 (F-295)** — gate on the compiled artifact adopters consume, never on intermediate agent output; "zero emissions = pass" is a false pass. Shapes FR-017 (empty histogram is failure) and M-5 (denial field reads `unverified`, never `[]`).
- **Entry 24 (F-373)** — path checks compare identities, never spellings (`[ -ef ]`, `resolve().is_relative_to`). Shapes FR-015's work-tree refusal.
- **Entry 1 (F-248)** — whole-tree byte-comparison fixtures drift on every doc addition; a `docs/architecture/01_system_design/README.md` edit requires regenerating `tests/fixtures/init-baseline-tree/` in the same commit (team-lead C-7).

## Industry Research
- **Claude Code sandbox** (public docs, saved 2026-11-16): network isolation via a local proxy honoured by proxy-aware tools only; `allowedDomains` start empty; `strictAllowlist`/`allowManagedDomainsOnly` are user/managed scope; credential `mask` requires `network.tlsTerminate` and `injectHosts` inside `allowedDomains`; `sandbox.credentials` covers sandboxed Bash only (Read/Write/WebFetch run outside); `excludedCommands` removes all isolation for the matched command. Third-party reports to keep in mind for FR-009: proxy TLS failures for Go binaries (`gh`), localhost cannot be allow-listed, a historical empty-allowlist bypass (fixed in v2.0.55, CVE-2025-66479), and an open report on HTTPS CONNECT tunnelling — the runbook should stamp the Claude Code version and treat the proxy as defence in depth, not a process boundary.
- **Auto mode** (public docs): classifier reads project `CLAUDE.md` but not project-scope `autoMode` blocks; `environment` grants trust, `hard_deny` only blocks; `"$defaults"` keeps built-ins; `/auto-mode-setup` drafts environment entries.
- **Transcript layout** (third-party docs and issue reports; no official spec): `~/.claude/projects/<slug>/<session>.jsonl`, subagents under `<session>/subagents/agent-<id>.jsonl`, legacy `isSidechain` inline form, per-entry `type`/`uuid`/`timestamp`/`parentUuid`; the layout is described as undocumented and brittle (issue reports). Confirms FR-017's minimal-contract, fail-loud design and the two-generation fixture.
- References: code.claude.com sandboxing, auto-mode-config, settings-reference, permission-modes; claudeissues.com reports 87296, 36363, 65482, 40213, 89165; anthropics/claude-code issues 17591 and 32175; claude-dev.tools JSONL format notes.

## Recommendations for Spec
- Keep the spec implementation-agnostic but anchor every "what" to the verified surfaces above (hosts, write set, schema surfaces), so plan can cite file:line without re-discovery.
- Treat command frontmatter as declared-only today (no `allowed-tools`/`model`); the matrix must say so and the guard may pin it once set.
- Make the guard's roster rule explicit ("no file can opt out") and bound any body scan to fenced shell blocks (TW-A3).
- State that the examples stay at their schema version and that the reconciliation precedes the additive field.
- Keep "zero denials" from being a pass signal anywhere (KB 22): the denial field and the egress probe both need positive evidence.
- Validate in a scratch adopter project installed from `install.sh`, never in the tachi repo (dev-time allow rules and hooks change the effective config).
