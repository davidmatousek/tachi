- `tachi_scoring.py` (D5). Its own strict `parse_date` is right, because `date.fromisoformat` accepts other forms from Python 3.11.
- The strict part loader and validators (D3, NFR-10).
- The four path checks. Each serves a different decision: D3's step 1, D7's spelling-aware resolver, R-6's reasons and the evidence walk.

- `plan_stage(batch_size=...)` (D6).
- `_label_level`, which D2's `trust-label` flag needs.
- The populator loaded by path (S-13).
