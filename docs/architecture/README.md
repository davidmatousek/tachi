(D3) **Deterministic-value rationale (FR-2 literal)** — the tag is a `dict.get` over the frozen 6-value enum (`affected_assets = component_asset_map.get(component, [])`, sorted), NOT a candidate for LLM judgement; encoding it as a deterministic lookup the LLM copies verbatim satisfies spec FR-002 literally and removes per-run variance at the source (the one thing Design A buys over the rejected LLM-transcribed Design B). (D4) **NFR-3 production cross-format consistency is test-checked, NOT structural (the `maestro_layer`/ADR-037 precedent)** — consistency between the `threats.md` block and the SARIF `affected_assets[]` bag is enforced in production by a **required, non-optional test check** (spec SC-006 multi-finding equality + SC-002 byte-identity), NOT structurally guaranteed in the LLM tier; the structural guarantee exists only in the Python script/regeneration tier; **we explicitly do NOT claim structural determinism on the production path** — a shared extractor cannot deliver it because production SARIF is LLM-authored. (D5) **The structural ideal is explicitly deferred (out of scope — the F-219 aspiration)** — genuinely structural production NFR-3 would route production SARIF through the Python scripts (orchestrator + risk-scorer write only `.md`; a deterministic step generates every `.sarif`); that is a pipeline re-architecture far exceeding F-260b, recorded as the known deferred ideal. **Schema**: `schemas/finding.yaml` gains an always-present `affected_assets` enum-array field (default `[]`), `schema_version` **1.8 → 1.9** (additive minor bump per ADR-026 rule + ADR-028 always-present-default arm). **NEW components**: `scripts/populate-affected-assets.py` (the value authority — pure stdlib, PAT-014, no new third-party deps) + `parse_affected_assets()` shared extractor in `scripts/sarif_common.py` (NEW, verification tier, separate from the emitters). **ADR-worthiness**: a schema field alone would warrant **no ADR** (ADR-026 minor-bump rule + ADR-028/037 precedents govern it), but the **production-tier election** (modifying the live LLM SARIF-authoring contracts) meets the criterion, so this **thin ADR** is committed per plan.md Q2 resolution / Architecture Decision AD-1 "The Determinism Mechanism". **23/23 tasks complete**; released via PR #303 squash-merged 2026-06-01 at `3d3d29f`. Cross-references ADR-026 (minor-bump rule), ADR-028 (additive-field + serialization-surface precedent — `affected_assets` follows the always-present-default arm, not the `source_attribution` omit-when-empty arm), ADR-037 (`maestro_layer` populator-wiring + test-checked-consistency precedent), ADR-021 (byte-deterministic baselines). Provenance: @north-echo asset-tag prototype (PR #262, v4.31.0) (Feature 302)

Production cross-surface consistency is **test-checked, NOT structural** in the LLM-authored markdown tier (the `maestro_layer` / ADR-037 posture inherited): the **required, non-optional** cross-surface gate `tests/scripts/test_maestro_cross_surface_consistency.py` (7-layer agreement + a negative L7 test, failing NAMING the offending layer + divergent surface) is wired into `.github/workflows/tachi-maestro-coverage.yml` in **F-250 lock-step** (workflow `paths:` ⇄ pytest invocation updated together; five render-IR surfaces — both extractors, both templates, the orchestrator directive — promoted from defense-in-depth to regression-necessary).
