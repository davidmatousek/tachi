# tachi in the Wild — Adopters

Real teams running tachi against real architectures. This page collects case studies from people who use it in production, and it's where prospective adopters can see peer signal in one place.

## How to submit

Sharing how you use tachi takes one of two paths:

1. **Case study** — copy [`case-study-template.md`](./case-study-template.md), fill it in, and either open a pull request adding your copy here or post it in Discussions. Everything identifying is opt-in via the template's consent block (anonymized is fine).
2. **Quick story** — drop a note in the [**In the Wild**](https://github.com/davidmatousek/tachi/discussions/categories/in-the-wild) Discussions category. No template required — tell us your stack, where tachi fits, and what it caught.

Either way, nothing identifying gets published without your explicit consent.
